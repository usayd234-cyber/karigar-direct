# Karigar Direct - Local Skilled Worker Directory

**Karigar Direct** is a responsive web application created as the final capstone project for the **Front-End Development Bootcamp at IT Excellence Circle (ITEC)**. 

The project addresses a common real-world problem: finding reliable local skilled workers (such as electricians, plumbers, painters, carpenters, and masons) without paying extra commissions to agency middlemen. 

---

## Key Features

- **Direct Contact:** Quick action buttons for direct calling and WhatsApp chat.
- **Bilingual Support:** Dynamic language toggle supporting both English and Urdu interface text.
- **Category Filtering:** Smooth JavaScript filtering to search workers by trade/profession.
- **Worker Registration:** Clean 2-column registration form (`register.html`) for new handymen to list their services.
- **Fully Responsive Design:** Optimized UI for mobile phones, tablets, and desktop displays using modern CSS layout techniques.

---

## Tech Stack

- **HTML5:** Semantic layout across multi-page structure (`index.html`, `about.html`, `register.html`).
- **CSS3:** Custom CSS variables, Flexbox, Grid, and media queries for responsive typography and components.
- **Vanilla JavaScript (ES6):** Pure JS DOM manipulation for category filtering, dynamic translation, and interactive UI states.

## Local Setup & Installation

To run this project locally on your machine, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/usayd234-cyber/karigar-direct.git
   ```

2. **Navigate to the project folder:**
   ```bash
   cd karigar-direct
   ```

3. **Launch the site:**
   - Double-click `index.html` to open it in your default web browser, or
   - Use the **Live Server** extension in Visual Studio Code for real-time reload.
